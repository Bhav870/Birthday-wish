# Birthday Wish

An interactive birthday greeting page made with HTML and CSS.

## Features

- Animated envelope that reveals the birthday message
- Background Happy Birthday music with a play/pause control
- Interactive cake-cutting button with a celebratory sound
- Photo gallery with an enlarged lightbox view
- Three-page birthday wish section with previous/next navigation
- Responsive layout for desktop and mobile screens

## Preview Locally

This project has no build step or dependencies.

1. Clone or download the repository.
2. Open `index.html` in a browser.

For the best local experience, serve the folder with a simple static server, for example:

```bash
python -m http.server
```

Then open `http://localhost:8000`.

## Customize

Edit the text, names, image URLs, and colors in `index.html` and `style.css` to create a personal birthday message.

The page uses Google Fonts, Unsplash images, and a YouTube audio embed, so an internet connection is needed for those external assets.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository's **Settings** tab.
3. Go to **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will provide the published page URL after deployment finishes.
